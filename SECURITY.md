# Security

vibereel reads private agent session logs, so leaks matter.

## Reporting

If you find a secret that slips past redaction, a path that leaks your home folder, or anything else security related, please report it privately through [GitHub security advisories](https://github.com/TanbirRamim/vibereel/security/advisories/new) or by email to contact.tanbirramim@gmail.com.

Please don't open a public issue, and never attach a real session log. A small hand-written line that reproduces the problem is perfect.

You should hear back within a few days.

## Supported versions

Only the latest release gets fixes.
